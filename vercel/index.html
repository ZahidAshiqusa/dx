WhatsApp Device Linking

WhatsApp Multi-Device authentication uses Baileys socket protocol. You can link using an 8-digit Pairing Code directly to your phone number, or scan the QR Code. Once linked, the session credentials are kept safe in your persistent backend container.

Multi-Cloud Deployment Endpoints

This project contains 4 platform-named directories. Your frontend on Vercel can dynamically communicate with any of your backend deployments. Enter your deployed URL below or choose from the presets:

RW

Railway Deployment

Folder: railway/
Unprobed

Standard continuous WebSocket daemon. Default PORT 8080 with automated health checking and zero-config deployment.

RD

Render Deployment

Folder: render/
Unprobed

Equipped with a built-in background keep-alive pinger and blueprint render.yaml on PORT 10000.

HK

Heroku Deployment

Folder: heroku/
Unprobed

Configured with native Procfile (web: node server.js) and dynamic $PORT allocation.

VC

Vercel & Localhost

Folder: vercel/
Unprobed

Default direct server proxy. Connects to the local development environment or embedded serverless endpoints.
